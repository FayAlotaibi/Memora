# Memora

Memora is an iOS travel experience app built with SwiftUI. It helps travelers create personalized travel challenges, explore daily tasks, and capture memories in a travel journal.

## Features
- Travel preferences and personalized challenges
- Daily tasks and journey progress
- Journal and memory pages
- Journey navigation and trip completion screens

## Technologies
- Swift
- SwiftUI
- SwiftData
- Xcode

## Open the project
1. On a Mac with Xcode, open `Memora.xcodeproj`.
2. Select a compatible iOS simulator or device.
3. Review signing settings if running on a physical device.
4. Build and run.

## Notes
This repository was prepared from the original student project. The Xcode project structure was renamed from QVoyage to Memora without intentionally changing application behavior. The existing bundle identifier is preserved to avoid altering signing identity. Build and runtime behavior have **not** been tested in Xcode.
